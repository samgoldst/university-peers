This repository contains a large network of U.S. postsecondary institutions and the comparison groups listed in their 2024 IPEDS Data Feedback Reports.

IPEDS, the Integrated Postsecondary Education Data System, is operated by the National Center for Education Statistics within the U.S. Department of Education. Its Data Feedback Report is “intended to provide institutions a context for examining the data they submitted to IPEDS.”

The repository contains two CSV files:

(1) `institutions.csv`:

&emsp;A list of institutions discovered by the crawler for which a 2024 Data Feedback Report could be successfully accessed and parsed. For each institution, the file includes its IPEDS UnitID (`school_id`), name (`name`), city (`city`), and whether its comparison group was selected by the institution itself or automatically generated by IPEDS (`peer_type`).

(2) `edges.csv`:

&emsp;A directed edge list describing the comparison network. Each row contains a source institution ID (`source_id`) and a target institution ID (`target_id`), meaning that the source institution’s Data Feedback Report listed the target institution as part of its comparison group.

All data in this repository was compiled from publicly available 2024 IPEDS Data Feedback Reports.

The dataset was collected using a recursive web crawler. The crawler began with the University of Wisconsin–Madison, where I currently attend:

https://nces.ed.gov/ipeds/dfr/2024/ReportHTML.aspx?unitId=240444

For every institution listed in a report’s comparison group, the crawler attempted to visit that institution’s Data Feedback Report and repeat the process. This continued until no additional accessible institutions remained to be processed.

In total, the crawler discovered 5,828 UnitIDs, of which 5,810 were successfully processed and 18 had unavailable or unparseable DFR pages.

I have not published the crawler used to collect this dataset. The underlying IPEDS pages are publicly accessible, and the collection methodology is described above.

A small number of institutions appeared in comparison groups and therefore have IPEDS UnitIDs, but their 2024 Data Feedback Report pages could not be successfully accessed or parsed.

Several of these missing reports have identifiable explanations. Some institutions closed or ceased operations around the 2024 reporting period, while others are administrative offices, university systems, or community-college districts rather than individual campuses. In other cases, the reason a 2024 DFR page is unavailable is unclear. These records were retained as target IDs because they were explicitly listed in another institution’s comparison group.

These institutions may therefore appear as `target_id` values in `edges.csv`, but not as `source_id` values. Their outgoing comparison-group edges are consequently unavailable in this dataset.
