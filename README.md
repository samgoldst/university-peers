This repository contains a network of U.S. postsecondary institutions and the comparison groups listed in their 2024 IPEDS Data Feedback Reports.

IPEDS, the Integrated Postsecondary Education Data System, is operated by the National Center for Education Statistics within the U.S. Department of Education. Its Data Feedback Report is “intended to provide institutions a context for examining the data they submitted to IPEDS.”

The repository contains two CSV files, as well as the scraper used to make them. Below are the descriptions of the CSV files:

&emsp;(1) `institutions.csv`:

&emsp;&emsp;A list of institutions discovered by the crawler for which a 2024 Data Feedback Report could be successfully accessed and parsed. For each institution, the file includes its IPEDS UnitID (`school_id`), name (`name`), city (`city`), and whether its comparison group was selected by the institution itself or automatically generated by IPEDS (`peer_type`).

&emsp;(2) `edges.csv`:

&emsp;&emsp;A directed edge list describing the comparison network. Each row contains a source institution ID (`source_id`) and a target institution ID (`target_id`), meaning that the source institution’s Data Feedback Report listed the target institution as part of its comparison group.

All data in this repository was compiled from publicly available 2024 IPEDS Data Feedback Reports.

The dataset was collected using a simple link-following web crawler. The crawler did not start from a complete list of IPEDS institutions. Instead, it began with the University of Wisconsin–Madison, where I currently attend:

&emsp;https://nces.ed.gov/ipeds/dfr/2024/ReportHTML.aspx?unitId=240444

In total, the crawler discovered 5,828 UnitIDs, of which 5,810 were successfully processed. 18 had unusable DFR pages. Those appear as `target_id` values in `edges.csv`, but not as `source_id` values.
